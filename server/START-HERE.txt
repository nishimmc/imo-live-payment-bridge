SECURITY
- In production, ALWAYS set ADMIN_PASSWORD and ADMIN_SESSION_SECRET in .env.local.
- Do not use the built-in local password in production.
- Set a real 64-hex IMO_ENCRYPTION_KEY and never change it after encrypted data exists.
- Never expose SUPABASE_SERVICE_ROLE_KEY in browser/client code.

SUPABASE
For production, set LOCAL_MODE=false, add Supabase credentials, and run supabase/schema.sql.
The schema migration includes price fields, booking access-token protection and duplicate Transaction-ID prevention.

LOCAL DATA
Profiles, bookings, settings and reviews are stored in .localdata/db.json. The app uses serialized writes and atomic file replacement for local-mode consistency.
